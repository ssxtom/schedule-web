# 课表助手 · iPhone 网页版

这是把《每周课表.xlsx》做成的**手机网页版**：在 iPhone 的 Safari 里打开，可以作为全屏 App 使用，并能「添加到主屏幕」变成一个图标。

## 怎么用

### 1. 直接用（本地文件）
把本文件夹拷到手机、或在电脑用浏览器打开 `index.html` 即可使用。桌面效果见下方。

### 2. 添加到主屏幕（推荐）
1. 在 iPhone 的 **Safari** 打开本页。
2. 点底部**分享**图标 → **添加到主屏幕**。
3. 点右上角**添加**。桌面出现「课表助手」图标，点开就是全屏 App 界面。

> 提示：网页要按 PWA 方式离线保存、图标更精致，需要把它**托管到线上（HTTPS）**。推荐用 GitHub Pages / Netlify / Cloudflare Pages 免费部署。我也准备了 `manifest.webmanifest` 与 `sw.js`，托管后自动启用离线与独立窗口模式。

## 内容

- **今日**：今天所有课（时间 / 课程 / 教室 / 教师），正在上的课高亮，并显示「下一节」倒计时。
- **课表**：14 节 × 周一~周日的完整周课表，自动高亮当前周和今天。
- **设置**：可修改每节课的上下课时间、开学日、提醒提前量、周末是否提醒（会保存在本机）；一键「导出整学期日历(.ics)」。

## 怎样真正实现 iPhone 上课提醒

网页**不能**像原生 App 那样在后台弹定时通知。最可靠的办法是：

**设置页 →「导出整学期日历(.ics)」** → 用 Safari 打开导出的文件 → 系统会提示加入 iPhone「日历」。之后系统日历会在每节课前按你设定的提前量自动提醒，无需打开网页。

如果想要网页自身的推送通知，则需要：
- 把 PWA 部署到 **HTTPS** 域名；
- 用户「添加到主屏幕」后授权通知；
- 需要一个推送后端 + APNs 发送服务。

如果你需要，我可以再帮你生成「用 GitHub Pages 部署」的步骤或推送方案。

## 数据结构

`index.html` 里的 `SESSIONS` 数组即你的真实课表（12 门课、18 周、真实周次与教室）。默认开学日 = 2026-09-07（第 1 周周一）。修改开学日、每节课时间都会保存在浏览器本地（localStorage）。
